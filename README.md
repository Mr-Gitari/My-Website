# Raphael Gitari Muchiri - Digital Business Card

A mobile-first digital business card, opened by scanning a QR code.
Plain HTML, CSS and JavaScript - no build step.

- `index.html` - the page
- `css/style.css` - styles (dark/light theme)
- `js/main.js` - theme toggle, typing effect, copy and share buttons
- `contact.vcf` - "Save to Contacts" file
- `Raphael-Gitari-Muchiri-CV.pdf` - "Download CV" file
- `images/photo.png` - profile photo

Deploy on Vercel: import this repository and click Deploy (no settings needed).
